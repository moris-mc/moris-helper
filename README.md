# moris`Helper` 1.0.0：總開關、輪盤調整與傳送鏡頭

安裝：玩家端換上 morisHelper-1.0.0.jar 並重啟遊戲。伺服器停服備份後，以 morisfolia-helper-cinematic.jar 替換原 Moris 插件，再啟動；這是完整 Moris 插件，不要重複放兩份。

X + F 預設開啟「一般設定」。
- 啟用小幫手：關閉後，模式輪盤、Shift + G 玩家檢視與容器預覽快捷鍵停用，容器預同步停止，傳送特效也停用；X + F 仍可開啟設定。聊天欄滑鼠按鈕、公告／通知與 Discord 狀態等原有背景功能保留。
- GrandTeleport 傳送特效：可獨立關閉，設定會保存。
- 輪盤設定：開啟按鍵（預設左 Alt）、半徑（48–110 GUI 像素）、水平／垂直偏移均可調整。輪盤會限制在視窗內，維持原本 OP 權限限制。放開自訂按鍵套用，中央或圈外取消，權限撤銷或總開關關閉時不送出指令。

傳送效果參考 GrandTeleport 的鏡頭構想，為 Minecraft 26.3 自行適配的功能子集，無需另裝 GrandTeleport：分段拉高、近距離空中平移及拉近；遠距離／跨世界使用淡出銜接，不強制載入中途區塊。不是完整移植原模組的 Voxy／Distant Horizons 等相容功能。原專案 README 與授權：https://github.com/hookuru/GrandTeleport 。MIT 授權文字附在 META-INF/licenses/GrandTeleport.txt，沒有重用其另行限制授權的自訂音效檔。

接入森友 /home、/phome（含選單選定家點）、/tpa、/tpahere 接受後真正移動的玩家、/spawn、/back。僅開啟家點選單、發送 TPA 邀請或找不到家點，不啟動效果。一般管理員 /tp 及暫時座標點傳送保持原流程。

啟用特效且已回報偏好的玩家，先有 19 ticks（正常約 0.95 秒）的拉高鏡頭，再由既有伺服器流程執行傳送；未裝本模組或關閉效果的玩家，沒有這段額外等待。實際傳送仍由原插件檢查權限、領地、坐姿與成功結果；失敗發出取消通知，伺服器清理背包鎖與待傳送狀態。特效期間抑制鍵盤移動與滑鼠轉向，開啟設定／暫停畫面、死亡、斷線或逾時會還原視角與控制；跨世界等待下載畫面結束後才開始拉近。

新增音效採 Minecraft 原生 enderman.teleport 與 amethyst_block.chime，音量參數均為 0.2。原有伺服器傳送完成音效已是 0.2，保持該值。原生主音量與 UI 音量仍有作用。

特效期間畫面下方顯示紅字：
本功能為娛樂特效功能，若不喜歡可以開啟"小幫手"模組關閉此功能

Folia 原始專案已更新 DiscordFeedService.java、TeleportWorker.java、HomeFeature.java、SpawnFeature.java、TeleportFeature.java，新增 TeleportCinematicBridge.java。原檔備份在 outputs/teleport-cinematic-backup-日期時間/。沒有部署或重啟執行中的伺服器。

驗證：Java 25 兩端編譯、完整 Gradle 檢查通過；新增實際 MaLiLib 設定序列化／還原、SDL 預設與自訂輪盤按鍵、停用後保留設定鍵、輪盤邊界／取消與選擇、分段升高／淡出／返回檢查。伺服器橋接測試驗證 opt-in、拒絕無效偏好、成功 ID 匹配／去重、取消、關閉與登出清理。尚未在實際 Minecraft／Folia／光影環境完成同世界、跨世界及取消情境實測。


# morisHelper 1.2.0

## 安裝
玩家端：移除舊 morisHelper JAR，放入 morisHelper-1.2.0.jar 並重新啟動 Minecraft。
伺服器端：以 morisfolia-helper-1.2.0.jar 替換現有 Moris 主插件，確保同一插件只有一份 JAR，正常重啟伺服器。這是完整 Moris 主插件，不是另外安裝的附加插件。尚未替你部署或重啟。
兩端均需更新，才能接收新的 GIF 嵌入預覽與領地／傳送陣事件。

## GIF
分享頁與圖片直連分開處理：用戶端接受 Klipy、Tenor、Giphy 分享頁，解析公開 OpenGraph 圖片；只允許指定 HTTPS 圖片 CDN，保留完整簽名參數。分享頁若擋住直接讀取，會顯示提示並保留點開查看。
伺服器 Discord 橋接除了附件，也會轉送嵌入圖片／GIF；支援 Discord 稍後補上的 MESSAGE_UPDATE 預覽，避免相同訊息與圖片重複轉送，維持管理頻道權限。
有效 GIF 可逐格播放。若網站只提供靜態預覽，則顯示該預覽；尚未加入 MP4／WebM 聊天縮圖解碼。
截圖的 dog-meme-white-dog.gif?backend=b2 網址實測 HTTP 404。請重新從 Discord 傳送 GIF 附件或可用分享連結；本版無法復原已無法取得的圖片。Discord 附件網址可能含有到期簽名，請保留完整參數。
GIF 縮圖仍有限制：單次下載 10 MiB、192×96、最多 120 幀或累計解碼 6400 萬像素，超出時播放已讀取部分。原圖視窗使用瀏覽器播放，不受縮圖幀數限制。

## 傳送特效
3 秒分段升空（高度 12／40／72，中間停頓約 0.42／0.48 秒）→ 近距離平移 1.1 秒 → 分段降回 2.8 秒。遠距離或跨世界以淡出銜接，載入完成才回到玩家。全程最多 15 秒保護。
新增漸進畫面模糊，使用原版模糊後製，在 HUD 之前處理，不修改玩家選項。與個別光影的實際顯示仍需遊戲內確認。
音效由介面分類改走主音量，固定 0.2，加入分段提示；抵達音效延至世界載入完成後，避免切換世界時被清除。仍遵守玩家主音量設定。
/res tp（含領地 GUI 入口）及傳送陣已接入；保留領地權限、GSit 限制、/back 記錄、成功／失敗訊息，傳送陣在延遲後再次確認玩家仍在範圍內。寵物跟隨改在傳送成功後。
X+F 的傳送特效開關及小幫手總開關仍生效；未安裝模組或關閉效果者不增加等待。

## 驗證
用戶端 Gradle offline build 全部檢查通過，包含 GIF 雙幀／延遲、分享頁解析／不可信目標拒絕、鏡頭停頓與模糊曲線、既有功能。
圖片視窗 Node 測試通過。伺服器 Java 25 編譯通過；模擬玩家排程驗證未啟用者立即傳送、啟用者延遲 60 tick、驗證失敗不傳送及事件生命週期。
未進行 Minecraft 實機測試；Klipy 直接 HTTP 取頁在本環境被網站驗證頁阻擋，因此另補伺服器嵌入預覽路徑，仍需實際傳送 GIF 驗證。

原始碼已同步到提供的 Folia 專案。變更前備份位於同目錄 gif-cinematic-backup-*。


# morisHelper 1.3.0

## 更新方式
玩家：以 morisHelper-1.3.0.jar 替換舊版並重開遊戲。
伺服器：以 morisfolia-helper-1.3.0.jar 替換 Moris 主插件，保留單一 Moris JAR，再正常重啟。兩端都需更新。尚未部署或重啟伺服器。

## 傳送
移除模糊後製，改成青藍色半透明濾鏡，強度逐漸進出；保留跨世界／遠距離淡出遮罩與既有特效開關。
升空音效分別對準 0ms、1020ms、2160ms 三段移動起點；降落提示對準 0ms、1232ms、2240ms。音量仍為 0.2，走主音量。主音量為零時仍不播放。

## Discord 聊天
GIF 分享網址及 GIF 直連不再重複顯示在文字行。保留一般連結與訊息文字，媒體列可以點開。
嵌入預覽優先選 GIF，其次 MP4／WebM 動畫，再選靜態封面；Discord 預覽尚未備妥時會等候並重新查詢一次。圖片通知及文字前綴／暱稱使用成員身分組顏色；無顏色時使用白色。
原生 GIF 縮圖持續逐格播放；MP4／WebM 以 Chromium 靜音循環播放，並支援點開後縮放與拖曳。同時最多 4 個影片預覽，離開可見區域後回收瀏覽器。
注意：實際 MP4 播放仍取決於內嵌 Chromium 的格式支援及來源是否可用；若網站只提供靜態圖，本版不能將該圖變成動畫。網站驗證頁／失效連結亦可能妨礙讀取。
圖片按實際比例預留行數，載入尺寸後自動重新排版，避免固定 8 行造成的大空白。
Discord 自訂表情保留名稱作為無模組玩家的文字替代，模組端顯示行內圖示，支援動態自訂表情。Discord 訊息中的一般 Unicode、ZWJ 家庭／旗幟也轉成 Twemoji 圖示；首次顯示需下載圖示，載入中使用小問號，不另佔圖片區域。

## 驗證
用戶端 Gradle offline build 全部通過，新增行內表情群組、零圖片空間、非 Discord 訊息保留、圖片行高、動態來源優先及音效時點檢查。
圖片視窗 Node 測試通過，包含靜音循環影片與分享頁優先選動畫。
伺服器 Java 25 編譯及聊天測試通過，包含成員顏色、動態表情 ID 與 GIF 網址過濾。
尚未進行 Minecraft／Chromium 實機播放與音效驗證，這部分仍需更新兩端後確認。
Folia 原始碼已同步；變更前備份在 chat-filter-backup-*。


# morisHelper 1.3.1

## 更新
玩家替換為 morisHelper-1.3.1.jar 並重開遊戲。
伺服器以 morisfolia-helper-1.3.1.jar 替換 Moris 主插件，再正常重啟；兩端均需更新，且各只保留一份舊插件／模組的替代版本。尚未部署或重啟。

## GIF／MP4
保留隱藏重複 GIF 網址，點擊媒體通知仍保留完整來源與 Discord 附件簽名。
MP4（H.264）改由內附的 JCodec 在背景執行緒解碼為循環畫格；聊天不再依賴 Chromium 是否支援該 MP4 編碼。
GIF 與 MP4 的點開視窗改為原生動畫檢視，支援符合視窗、1:1、縮放、拖曳與 Esc 返回。PNG 等靜態原圖仍使用既有瀏覽器視窗；WebM 仍採瀏覽器播放。
Klipy 等分享預覽可能是單格 GIF 封面，所以有 MP4 動畫時優先使用 MP4。使用者直接上傳的 GIF 附件維持 GIF 逐格解碼。
解碼與快取有尺寸／畫格／時間上限；動畫視窗使用預覽解析度，非原始高解析影片。過大或不支援的媒體會顯示失敗狀態；主模組內不下載或執行外部解碼程式。

綠色【括號】＋黃色 DC；用戶顯示名稱套用 Discord 成員身分組顏色。無身分組顏色者顯示白色。
